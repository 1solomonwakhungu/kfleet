How to view

Open any file directly in a browser, or serve the folder: python3 -m http.server 4173 --directory docs/mockups/primer.

Every color, radius, and border comes from @primer/primitives functional tokens, so the same markup renders correctly in both themes. Use the toggle in the top right to switch.
